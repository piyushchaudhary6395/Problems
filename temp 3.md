# Linear Programming
The objective function has to be linear and the inequalities that define the program have to be of the form something linear on  LHS is less than or equal to some constants.

## Algorithms to solve LP
- Danzig: Simplex Algorithm: W.C-> exponential. In practice-> polynomial
- Kachiyan: Ellipsoidal Method
- Karmankan: Interior Point  Methods: LPs (very fast)
