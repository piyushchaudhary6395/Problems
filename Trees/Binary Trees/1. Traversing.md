If we do an in order traversal on a tree, our numbers are going to come out in ascending order.
![[Screenshot (468).png]]
If we want these numbers to come out in descending order then switch the order of visiting left and right sub trees.
![[Screenshot (469).png]]

The interesting things about post order traversals is that we traverse the tree from its leaves all the way to its root. This is very useful in solving a lot of tree problems. In a lot of cases we should start by visiting the leaves nodes first, we are going to calculate some values and pass those values up the tree until we get to the root.
