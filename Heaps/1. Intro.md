## Application of heaps
![[Pasted image 20240620192329.png]]

We use an array to implement a heap, even though a heap is conceptually a binary tree but because heaps are complete binary trees and we don't have holes in them, it's more efficient to implement them using an array. It is going to have a smaller footprint in memory, if we use arrays because we don't have a node class and pointers.
