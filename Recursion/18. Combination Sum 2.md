```js
Given a collection of candidate numbers (`candidates`) and a target number (`target`), find all unique combinations in `candidates` where the candidate numbers sum to `target`.

Each number in `candidates` may only be used **once** in the combination.

**Note:** The solution set must not contain duplicate combinations.

**Example 1:**

**Input:** candidates = [10,1,2,7,6,1,5], target = 8
**Output:** 
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]

**Example 2:**

**Input:** candidates = [2,5,2,1,2], target = 5
**Output:** 
[
[1,2,2],
[5]
]

**Constraints:**

- `1 <= candidates.length <= 100`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`
```

## Brute Force
Here we are using a set of vector to keep from storing duplicate elements and we are only selecting an element once. We are sorting the array before passing it to the function so that the sub-sequences are generated in a sorted order and sorting the vector before storing it into the set. The set will take care of sorting the vectors within it.
```cpp
void combo(vector<int> candidates, set<vector<int>>& ans, vector<int> current, int target, int size, int i = 0) {
        if(i >= size) {
            if(target == 0)
                ans.insert(current);
            return ;
        }

        if(target == 0) {
            ans.insert(current);
            return ;
        }

        combo(candidates, ans, current, target, size, i+1);

        current.emplace_back(candidates[i]);
        if(target >= candidates[i])
            combo(candidates, ans, current, target-candidates[i], size, i+1);
    }

    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        set<vector<int>> ans;
        vector<int> current;
        int size = candidates.size();
        sort(candidates.begin(), candidates.end());

        combo(candidates, ans, current, target, size);

        vector<vector<int>> result(ans.begin(), ans.end());

        return result;
    }
```
Time Complexity: 2^t * k * log (of whatever the set size is)

## Optimal
We are trying to pick every element once, so we use a loop for this, to pick each element once from the current index towards the end. 

When it is possible to pick the element, meaning that we are not picking a duplicate element and target is greater than or equal to the element being chosen, we will add it to `current` vector as a possible combination, after that there will be a recursion call to pick the next element. 

When we come back from the recursion the elements that we have added into `current` need to be removed as well so that the other recursion calls can use the `current` vector for themselves as it was previously (in it's right state).

In two cases we will not be able to pick an element if it is greater than `target` because if it happened then the elements to it's right will only be bigger and if it has been chosen previously.

We do `i > ind` so that if it is the first time picking that element then that element cannot repeat even though the previous element is a duplicate. For example [1, 1, 1, 2, 2] when we are on the 4th index since we are picking it for the first time we can put it in the combination. 

Therefore `i > ind` means it is not the first time you are picking up that element, so for the 4th this condition will become false and we will pick up that element.
```cpp
#include <bits/stdc++.h>
using namespace std;

void combo(vector<int> candidates, vector<vector<int>>& ans, vector<int> current, int target, int size, int ind) {
	if(target == 0) {
		ans.emplace_back(current);
        return ;
    }

	for(int i = ind; i < size; i++) {
		if(i > ind && candidates[i] == candidates[i - 1])
			continue;
        if(candidates[i] > target) break;

        current.emplace_back(candidates[i]);
        combo(candidates, ans, current, target-candidates[i], size, i+1);
        current.pop_back();
        }
    }

int main() {
	vector<int> candidates = {2, 5, 2, 1, 2};
	int target = 5;
	vector<vector<int>> ans;
    vector<int> current;
    int size = candidates.size();

    sort(candidates.begin(), candidates.end());  

    combo(candidates, ans, current, target, size, 0);

	for(auto i : ans) {
		for(auto j : i) cout << j << " ";
		cout << endl;
	}
}
```

Time Complexity: Assuming all the elements are unique, the number of sub-sequences that we will get will be 2^n because whenever there are `n` unique elements, the no. of different unique combinations or sub-sequences that the array can generate is 2^n.

`k` for putting the combination into the `ans` vector.

O(2^n * k)

Space Complexity: k * x (ignoring the auxiliary space used by recursion)
k = average no. of combinations of x length
